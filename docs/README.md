# 昭昭专属个人站 🌸

> **我的工作、成长、情绪与爱人的记录空间**

一款为拥有特殊情感链接、梦角链接、精神寄托的用户设计的全功能个人成长工作台，适配 vivo iQOO Neo9，支持 PWA 安装。

## 部署与安装

### 方法 1：本地预览（开发）

```bash
cd zhaozhao-station
python3 -m http.server 8090
# 访问 http://localhost:8090
```

### 方法 2：作为 PWA 安装到手机

1. 部署到任何 HTTPS 静态托管服务（Vercel/Netlify/GitHub Pages）
2. iQOO Neo9 上用 Chrome 打开网址
3. 点击右上角"添加到主屏幕"
4. 像 App 一样使用

### ⚠️ 重要：数据保全

1. **iQOO Neo9 本地浏览器数据** ≠ 云端永久
2. **预览地址可能过期** → 数据可能丢失
3. **解决方案**：定期到「设置 → 数据备份 → 导出 JSON」
4. **建议**：每月导出一次备份
5. **数据恢复**：在「设置 → 数据备份 → 导入 JSON」

## 技术栈

- **前端**：纯原生 JavaScript（无框架依赖）
- **数据**：IndexedDB + Web Crypto API
- **图表**：Chart.js (CDN)
- **PWA**：Service Worker + Web App Manifest
- **样式**：CSS 变量 + 响应式

## 隐私声明

- 所有数据**默认存储在本地**，不上传云端
- **AI 调用需要用户主动配置 API Key**
- API Key 使用 Web Crypto 加密本地保存
- 隐私模块（灵魂链接、链接星图、跨维沟通）支持**独立密码保护**
- AI 文本**明确标注**为象征性内容
- **不把 AI 对话/同步性/梦境自动算作现实互动**

## 已知限制

1. **无后端**：纯前端实现，云同步需用户自己配置
2. **浏览器 CORS**：某些 AI 供应商需要 Relay 服务器
3. **PWA 后台限制**：定时主动消息只能在应用打开时检查
4. **本地存储依赖**：清浏览器数据/换浏览器会导致数据不可访问
